Detailed Description

scene which will be used by the app to render n screen

every frme the app clears the screen

Pixel coordinates passed to the mouse callbacks use the rasterizer's convention: origin bottom-left, y up, 0 <= x < width, 0 <= y < height.

The app reserves ESC (quit), TAB (next scene) and F5 (reload shaders).
