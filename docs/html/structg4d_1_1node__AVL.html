Detailed Description

template<typename T>
struct g4d::node_AVL< T >

AVL tree node: a tree_node plus a balance factor.

balance = height(right subtree) - height(left subtree), so +1 means right-heavy, -1 left-heavy and 0 balanced. In a valid AVL tree it is always -1, 0 or +1.

This is deliberately NOT derived from tree_node<T>. A derived node would inherit tree_node<T>* left/right, so n->left->balance would not compile and every child access in the tree code would need a cast. With its own node_AVL* children, the same generic tree code works for both node types.
