Detailed Description

template<typename T, typename Node = tree_node<T>>
requires std::totally_ordered<T> && tree_node_type<Node, T>
class g4d::raster_tree< T, Node >

A binary search tree that lays itself out and draws itself into a g4d::frame.

Layout is the level-by-level algorithm from the paper (two recursive passes, see modify() and place() instead of the iterative approach by Shannon and Wetherell).

Template Parameters
Tvalue type, must be totally ordered
Nodenode type, see g4d::tree_node_type (tree_node<T> or node_AVL<T>, or your own)

Node labels: set config.text to a text_raster and every node shows its value, centred inside the circle. Derived classes can add more through draw_node().

Needs g4d::frame to provide width() and height() (const) accessors.

Warning
The layout and the plain BST removal are recursive: a degenerate tree with ~100k nodes can overflow the stack. (Balanced trees such as avl_tree are not affected.)
