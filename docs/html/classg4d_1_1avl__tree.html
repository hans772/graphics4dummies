Detailed Description

template<typename T>
requires std::totally_ordered<T>
class g4d::avl_tree< T >

A self-balancing (AVL) binary search tree that draws itself.

Every node keeps balance = height(right) - height(left), which is always -1, 0 or +1. Insertion and deletion walk back up the path they came down, update the balance factors and rotate where a factor would reach +-2, so lookups, insertions and deletions are all O(log n) and the height stays below ~1.44 * log2(n + 2).

When config.text is set (see raster_tree::style):

  • the node's value is printed inside its circle, and
  • its balance factor ("+1", "0" or "-1") is printed above it, shifted to the side away from the edge to its parent so the edge does not run through the text.

Because the height is logarithmic, the recursion in layout and drawing is always shallow.
