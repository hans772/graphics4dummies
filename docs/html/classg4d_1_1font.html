Detailed Description

A fixed-cell bitmap font loaded from a glyph sheet (one PNG holding a grid of equally sized glyph cells) and a manifest.

Folder layout:

fonts/
<font_name>/
manifest
<glyph_sheet>.png

Manifest (Custom file with 4 rows)

[filename] "<glyph sheet filename relative to this directory wrapped in quotes>"
[start_offset] <ascii value of the first ascii character in the glyph sheet>
[glyphs_per_row] <number of glyphs per row>
[glyphs_per_col] <number of glyphs per columns>

A glyph pixel is "lit" if it is opaque and light (luminance > 127) when the image has no transparency, or if its alpha is > 127 when the image has transparent pixels. (So white-on-black and anything-on-transparent sheets work; black-on-white would be inverted.)
