Detailed Description

Rasterizes strings into a g4d::frame using a g4d::font.

Coordinates use the frame's convention (origin bottom-left, y up). The anchor (x, y) of draw() is the TOP-LEFT pixel of the text block; the text extends to the right and downward (towards smaller y). '
' starts a new line, '\r' is ignored.

Strings are read byte by byte, so each byte is one character code (0-255). That matches ASCII exactly; UTF-8 multi-byte characters appear as several glyphs. Characters without a glyph in the font are skipped but still advance the pen.

Everything goes through frame::draw_pixel, so text partly or fully outside the frame is clipped safely.

The renderer keeps a reference to the font, so the font must outlive it.
